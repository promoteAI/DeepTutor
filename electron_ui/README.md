# DeepTutor Electron Desktop

Electron wrapper for DeepTutor — spawns the Python launcher and embeds the Web UI in a native window.

## Structure

- `src/main.ts` — Electron main process (spawn launcher, manage windows/tray, IPC)
- `src/preload.ts` — contextBridge IPC interface
- `src/types.d.ts` — Renderer type declarations
- `index.html` — Loading screen with iframe injection
- `electron-builder.yml` — electron-builder config
- `package.json` — Dependencies: electron, electron-builder, typescript
- `dist/` — Compiled JS (generated by tsc)

## Build

### Prerequisites

1. Install Python dependencies:
   ```bash
   pip install -e .
   ```

2. Build the web frontend and prepare the packaged bundle:
   ```bash
   python scripts/prepare_web_package.py --skip-build
   ```

3. Install Electron dependencies:
   ```bash
   cd electron_ui && npm install
   ```

4. Compile TypeScript:
   ```bash
   npx tsc --project tsconfig.json
   ```

### Platform-specific builds

```bash
# Windows
npx electron-builder --win --x64
# Output: ../dist/electron_ui/DeepTutor-Setup-{version}-win-x64.exe

# Linux
npx electron-builder --linux --x64
# Output: ../dist/electron_ui/DeepTutor-{version}-linux-x64.AppImage
#         ../dist/electron_ui/DeepTutor-{version}-linux-x64.deb

# macOS
npx electron-builder --mac --x64
# Output: ../dist/electron_ui/DeepTutor-{version}-macos-x64.dmg
#         ../dist/electron_ui/DeepTutor-{version}-macos-x64.zip
```

## Run in Development

```bash
cd electron_ui && npx electron .
```

## Key Design Decisions

- **Launch model**: Electron spawns `python -m deeptutor_cli.main start --no-browser`
- **URL detection**: Matches launcher stdout lines containing the frontend port (e.g. `:3782`)
- **User data**: Stored in `%APPDATA%/DeepTutor` (written by launcher, not Electron)
- **Packaged mode**: Launcher auto-detects `deeptutor_web` package and skips rebuild
- **Tray icon**: Uses `assets/figs/logo/logo.png` with Show/Hide/Restart/Quit menu
